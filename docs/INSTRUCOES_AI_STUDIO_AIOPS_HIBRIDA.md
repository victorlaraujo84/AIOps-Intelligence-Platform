# Instruções para Google AI Studio — Evolução Híbrida da AIOps Intelligence Platform

**Data:** 19/11/2026  
**Repositório:** https://github.com/victorlaraujo84/AIOps-Intelligence-Platform  
**Objetivo:** Evoluir a aplicação existente, sem reconstruí-la, para uma plataforma híbrida de observabilidade e inteligência operacional de TI, redes/telecom, IoT, energia e ambiente.

Este documento versiona as especificações de evolução híbrida (Fases 0 a 6) executadas sobre a base do projeto, preservando compatibilidade, isolamento multi-tenant, estados honestos (`NOT_CONFIGURED`, `NO_DATA`, `SOURCE_STALE`, `INSUFFICIENT_DATA`, `MODEL_NOT_VALIDATED`, `PREDICTION_UNAVAILABLE`), e bloqueio de coleta sem escopo autorizado.
